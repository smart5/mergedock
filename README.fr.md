## Un seul espace de travail pour chaque comparaison

MergeDock réunit les fichiers sources, les différences, le résultat fusionné, la recherche, la vue d’ensemble des positions, les informations d’encodage et les actions d’enregistrement. Vous passez ainsi de l’examen à la résolution sans perdre votre position.

- **Comparaison de texte :** panneaux 2-Way synchronisés, différences par ligne et dans la ligne, recherche, coloration syntaxique, édition, actions de copie et export au format Unified Diff ou Patch.
- **Fusion à 3 voies :** comparez la base et les deux révisions, protégez les zones non résolues, choisissez une résolution et vérifiez le résultat avant de l’enregistrer.
- **Fichiers très volumineux :** l’accès indexé maintient la zone visible réactive sans charger tout le document dans l’interface.
- **Comparaison de dossiers :** parcourez les sous-dossiers, filtrez les résultats, consultez les métadonnées et confirmez les copies ou suppressions avant toute modification sur le disque.
- **Comparaison d’images :** inspectez les écarts de pixels et de dimensions avec les vues côte à côte, superposition, curseur, clignotement et différence.
- **Comparaison binaire :** examinez les changements octet par octet lorsqu’une interprétation en texte n’est pas adaptée.
- **Flux Git :** ouvrez une comparaison depuis `git difftool` ou une résolution de conflit depuis `git mergetool`.

## Traitement local par conception

- La comparaison et la fusion s’exécutent sur votre Mac.
- Le contenu des fichiers n’est pas envoyé à un service de comparaison externe.
- MergeDock utilise les panneaux d’autorisation macOS pour les fichiers et dossiers que vous choisissez.
- L’app ne contient ni SDK publicitaire ni suivi inter-applications.
- Les données de récupération et l’historique des comparaisons restent sous votre contrôle.

Consultez la [Politique de confidentialité](https://mergedock.net/privacy.html?lang=fr) pour en savoir plus.

## Assistance

Consultez d’abord la [page d’assistance MergeDock](https://mergedock.net/support.html?lang=fr). Vous pouvez aussi [ouvrir une demande d’assistance sur GitHub](../../issues/new/choose) ou écrire à [support@mergedock.net](mailto:support@mergedock.net).

Pour signaler un problème, indiquez :

1. Les versions de MergeDock et de macOS.
2. Le mode de comparaison utilisé.
3. L’action effectuée et le résultat attendu.
4. Le résultat obtenu et, le cas échéant, le message d’erreur exact.
5. Des captures ou données d’exemple expurgées, uniquement si elles sont nécessaires.

> **Ne joignez aucun fichier source confidentiel, identifiant, renseignement personnel ou journal non expurgé.**
