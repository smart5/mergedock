## 所有比较任务，一个工作区即可完成

MergeDock 将源文件、差异、合并结果、搜索、位置概览、编码信息和保存操作集中在同一个工作区中。从检查到解决问题，始终能够保持当前上下文。

- **文本比较：** 同步滚动的 2-Way 窗格、逐行和行内差异、搜索、语法高亮、编辑、复制操作，以及 Unified Diff 或 Patch 导出。
- **3-Way 合并：** 比较基准文件和两个修订版本，保护尚未解决的区域，选择解决方案，并在保存前检查合并结果。
- **超大文件：** 通过索引访问保持可见区域流畅，无需一次性将整个文档载入界面。
- **文件夹比较：** 检查嵌套文件夹、筛选结果、查看元数据，并在更改磁盘内容前确认复制或删除操作。
- **图像比较：** 使用并排、叠加、滑块、闪烁和差异视图检查像素及尺寸变化。
- **二进制比较：** 当文件不适合按文本解读时，逐字节检查变化。
- **Git 工作流程：** 从 `git difftool` 打开比较，并从 `git mergetool` 开始解决冲突。

## 以本地处理为核心

- 文件比较和合并均在您的 Mac 上完成。
- 文件内容不会上传到外部比较服务。
- MergeDock 通过 macOS 权限面板访问您选择的文件和文件夹。
- 应用不包含广告 SDK，也不会进行跨应用跟踪。
- 恢复数据和比较历史记录始终由您管理。

详情请阅读[隐私政策](https://mergedock.net/privacy.html?lang=zh-Hans)。
