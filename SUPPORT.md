# MergeDock Support

For troubleshooting, setup guidance, purchase questions, and common answers, visit the [MergeDock Support page](https://mergedock.net/support.html).

## Report a problem

Use the [bug report form](../../issues/new?template=bug-report.yml) for a reproducible product issue. Include:

1. Your MergeDock version and build number.
2. Your macOS version.
3. The comparison mode you were using.
4. The smallest set of steps that reproduces the issue.
5. The expected and actual results, including the exact error message when available.

You may write your report in any of the languages documented in this repository.

## Private support

For account, purchase, privacy, or security-sensitive questions, email [support@mergedock.net](mailto:support@mergedock.net). Do not place confidential files or credentials in a public issue.

## Before attaching files

MergeDock is often used with source code and private documents. Please create a minimal sample that reproduces the issue, or remove all confidential content before attaching anything.

Never attach:

- Credentials, API keys, certificates, or access tokens
- Personal or customer information
- Confidential source files or repository history
- Unredacted file paths or logs that reveal private information
