# Security Policy

## Reporting a security issue

Please do not open a public GitHub issue for a suspected vulnerability, privacy issue, permission bypass, or data-loss risk.

Email [support@mergedock.net](mailto:support@mergedock.net) with:

- The MergeDock and macOS versions involved
- A clear description of the behavior and its possible impact
- Reproduction steps that do not expose confidential data
- Whether the issue affects file access, saving, recovery, Git integration, or another area

Do not send real credentials, private keys, customer data, or confidential source files. A small, sanitized example is preferred when one is necessary.

We will review the report and may ask for additional details through a private channel.

## Supported versions

Security updates are provided for the latest version of MergeDock available from the Mac App Store.
