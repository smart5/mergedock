## 모든 비교를 위한 하나의 작업 공간

MergeDock은 원본 파일, 차이, 병합 결과, 검색, 위치 개요, 인코딩 정보, 저장 기능을 하나의 작업 공간에 모아 줍니다. 현재 위치를 놓치지 않고 검토부터 해결까지 이어갈 수 있습니다.

- **텍스트 비교:** 동기화된 2-Way 패널, 줄 단위 및 줄 내부 차이, 검색, 구문 강조, 편집, 복사 작업, Unified Diff 또는 Patch 내보내기를 지원합니다.
- **3-Way 병합:** 기준 파일과 두 변경본을 비교하고, 미해결 영역을 보호한 상태에서 해결 방법을 선택한 뒤 저장 전에 병합 결과를 확인합니다.
- **대용량 파일:** 인덱스 기반 접근으로 전체 문서를 한꺼번에 화면에 올리지 않고도 현재 보이는 영역을 빠르게 확인할 수 있습니다.
- **폴더 비교:** 하위 폴더, 필터, 메타데이터를 검토하고 디스크의 내용이 바뀌기 전에 복사 또는 삭제 작업을 확인합니다.
- **이미지 비교:** 나란히, 오버레이, 슬라이더, 깜박임, 차이 보기로 픽셀 및 크기 변경을 살펴봅니다.
- **바이너리 비교:** 텍스트로 해석하기 어려운 파일의 변경을 바이트 단위로 확인합니다.
- **Git 작업 흐름:** `git difftool`에서 비교를 열고 `git mergetool`에서 충돌 해결을 시작합니다.

## 텍스트 비교

변경 블록을 검토하고 차이 사이를 이동하며 허용된 쪽을 직접 편집할 수 있습니다. 인코딩과 줄 끝 형식도 항상 확인할 수 있습니다.

<p align="center"><img src="assets/text-compare-en.webp" alt="MergeDock 2-Way 텍스트 비교" width="100%"></p>

## 폴더 비교

동일함, 변경됨, 한쪽에만 있음, 형식이 다름을 한눈에 확인합니다. 항목을 더 자세히 비교하거나 확인 후 복사할 수 있습니다.

<p align="center"><img src="assets/folder-compare-en.webp" alt="MergeDock 폴더 비교" width="100%"></p>

## 3-Way 병합

충돌을 해결하는 동안 기준 파일과 두 변경본이 같은 위치에 맞춰 표시됩니다. 미해결 영역은 해결 방법을 선택할 때까지 편집되지 않도록 보호됩니다.

## 로컬 우선 설계

- 파일 비교와 병합은 Mac에서 처리됩니다.
- 파일 내용은 외부 비교 서비스에 업로드되지 않습니다.
- 선택한 파일과 폴더에는 macOS 권한 패널을 통해 접근합니다.
- 광고 SDK나 앱 간 추적 기능이 포함되어 있지 않습니다.
- 복구 데이터와 비교 기록은 사용자가 직접 관리할 수 있습니다.

자세한 내용은 [개인정보 처리방침](https://mergedock.net/privacy.html?lang=ko)을 확인하세요.
