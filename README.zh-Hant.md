## 所有比較工作，都在同一個工作區

MergeDock 將來源檔案、差異、合併結果、搜尋、位置概覽、編碼資訊和儲存操作集中在同一個工作區。從檢查到解決問題，都能保留目前的工作脈絡。

- **文字比較：** 同步捲動的 2-Way 窗格、逐行與行內差異、搜尋、語法醒目提示、編輯、複製操作，以及 Unified Diff 或 Patch 匯出。
- **3-Way 合併：** 比較基準檔案與兩個修訂版本，保護尚未解決的區域，選擇解決方式，並在儲存前檢查合併結果。
- **超大型檔案：** 透過索引存取維持可見區域的流暢度，不必一次將整份文件載入介面。
- **資料夾比較：** 檢查巢狀資料夾、篩選結果、檢視中繼資料，並在變更磁碟內容前確認複製或刪除操作。
- **圖片比較：** 使用並排、疊加、滑桿、閃爍和差異檢視，確認像素及尺寸變化。
- **二進位比較：** 當檔案不適合以文字解讀時，逐位元組檢查變化。
- **Git 工作流程：** 從 `git difftool` 開啟比較，並從 `git mergetool` 開始解決衝突。

## 3-Way 合併

解決衝突時，基準檔案與兩個修訂版本會持續保持對齊。選擇解決方式之前，未解決區域會受到保護，避免誤編輯。

## 以本機處理為核心

- 檔案比較與合併都在您的 Mac 上完成。
- 檔案內容不會上傳到外部比較服務。
- MergeDock 透過 macOS 權限面板存取您選擇的檔案和資料夾。
- App 不包含廣告 SDK，也不會進行跨 App 追蹤。
- 復原資料和比較記錄始終由您管理。

詳情請閱讀[隱私權政策](https://mergedock.net/privacy.html?lang=zh-Hant)。
